# Auto Ticket Classification Using Flow Designer

## Project Overview
This project aims to automatically classify support tickets based on their descriptions and assign them to the appropriate support groups using classification rules.

## Objectives
- Automatically classify support tickets.
- Identify ticket categories.
- Assign tickets to suitable support groups.
- Reduce manual ticket handling.

## Technologies Used
- ServiceNow Flow Designer
- JavaScript
- GitHub

## Project Files
- Project-Report.pdf – Project documentation.
- classification_rules.js – Sample ticket classification program.
